# Student Management System

CRUD web application for managing student records.

## Features
- Add, view, search, edit and delete students
- SQLite database
- Responsive UI

## Tech Stack
Python, Flask, SQLite, HTML, CSS

## Run on Windows
```bash
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

The database is created automatically. Do not upload `students.db` or `venv`.
